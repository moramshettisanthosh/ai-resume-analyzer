# AI Resume Analyzer

AI Resume Analyzer is a Spring Boot based web application that analyzes resumes and compares them with job descriptions to calculate an ATS (Applicant Tracking System) score.

## Features

- Upload Resume (PDF)
- Extract Resume Text using Apache PDFBox
- Compare Resume with Job Description
- Detect Matched Skills
- Identify Missing Skills
- Calculate ATS Resume Score
- Provide Skill Recommendations
- Clean UI using Thymeleaf

## Technologies Used

- Java
- Spring Boot
- Thymeleaf
- Apache PDFBox
- HTML / CSS
- Maven

## How It Works

1. User uploads a resume.
2. System extracts text from the PDF.
3. Skills are matched with job description.
4. Matched and missing skills are identified.
5. ATS score is calculated and displayed.
